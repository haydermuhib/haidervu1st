Topic: Graphs & Trees
Question: What does it mean by the preservation of edge endpoint function in the definition of isomorphism of graphs?

Model Solution / Answer:
Preservation of Edge Endpoint Function in Graph Isomorphism:

1. Formal Definition:
Let G = (V, E) and G' = (V', E') be two graphs with edge endpoint functions γ: E → {{u, v} | u, v ∈ V} and γ': E' → {{u', v'} | u', v' ∈ V'}.
An isomorphism between G and G' consists of two bijective functions:
  - A vertex bijection f: V → V'
  - An edge bijection g: E → E'
such that the edge endpoint function is preserved.

2. Mathematical Meaning of Preservation:
Preservation of the edge endpoint function means that for every edge e ∈ E, if e connects vertices u and v in G (i.e., γ(e) = {u, v}), then the corresponding edge g(e) in G' must connect f(u) and f(v) in G' (i.e., γ'(g(e)) = {f(u), f(v)}).

3. Significance:
This condition guarantees that the structural adjacency and edge connectivity are strictly preserved: two vertices are connected by an edge in G if and only if their images under f are connected by the corresponding edge in G'.

Question 2 (ID: 2, Marks: 3 Marks):
Topic: Graphs & Trees
Question: Is there any method of identifying whether given graphs are isomorphic or not without explicitly finding the two bijection functions?

Model Solution / Answer:
Determining Graph Isomorphism Without Explicit Bijections (Using Isomorphic Invariants):

1. The Isomorphism Invariant Approach:
While proving that two graphs ARE isomorphic ultimately requires demonstrating an isomorphism (or bijective mapping), we can definitively prove that two graphs are NOT isomorphic by checking 'isomorphic invariants'—properties that must be identical in any pair of isomorphic graphs.

2. Necessary Conditions (Isomorphic Invariants):
If G and G' are isomorphic, they must have:
  a. The same number of vertices: |V(G)| = |V(G')|.
  b. The same number of edges: |E(G)| = |E(G')|.
  c. The same degree sequence: The sorted list of vertex degrees must be identical.
  d. The same number of connected components.
  e. The same number of cycles of each specific length k (e.g., triangles, 4-cycles).
  f. The same adjacency matrix spectrum (eigenvalues).

3. Decision Criterion:
  - If ANY of these invariants differ between G and G', then G and G' are NOT isomorphic.
  - However, if all these invariants match, the graphs might still not be isomorphic. To prove isomorphism positively, one must exhibit the bijection f: V(G) → V(G') that preserves adjacency.

Question 3 (ID: 3, Marks: 3 Marks):
Topic: Graphs & Trees
Question: What are Complementary Graphs?

Model Solution / Answer:
Complementary Graphs (Graph Complement):

1. Formal Definition:
Let G = (V, E) be a simple undirected graph. The complement of G, denoted by G' or Ḡ (G-bar), is a simple graph whose vertex set is identical to V, but whose edge set E(Ḡ) consists of all edges that are NOT present in G.

2. Set Formulation:
E(Ḡ) = { {u, v} | u, v ∈ V, u ≠ v and {u, v} ∉ E(G) } = E(K_n) \ E(G),
where K_n is the complete graph on n = |V| vertices.

3. Key Properties:
  - |E(G)| + |E(Ḡ)| = n(n - 1) / 2 = |E(K_n)|.
  - Two vertices u and v are adjacent in Ḡ if and only if they are not adjacent in G.
  - The complement of the complement is the original graph: (Ḡ)̄ = G.
  - A self-complementary graph is isomorphic to its own complement (e.g., C_5, the 5-cycle).

Question 5 (ID: 5, Marks: 3 Marks):
Topic: Graphs & Trees
Question: Are isomorphic graphs reflexive, symmetric, and transitive (Is graph isomorphism an equivalence relation)?

Model Solution / Answer:
Graph Isomorphism as an Equivalence Relation:

Yes, graph isomorphism is an equivalence relation on the set of all graphs because it satisfies reflexivity, symmetry, and transitivity:

1. Reflexive:
Every graph G is isomorphic to itself (G ≅ G). The identity mapping id_V: V → V defined by id_V(v) = v and id_E(e) = e is a trivial isomorphism that preserves adjacency.

2. Symmetric:
If G_1 ≅ G_2, then G_2 ≅ G_1. If f: V(G_1) → V(G_2) is an isomorphism, its inverse function f^(-1): V(G_2) → V(G_1) is also a bijection that preserves edge endpoints and non-adjacency.

3. Transitive:
If G_1 ≅ G_2 and G_2 ≅ G_3, then G_1 ≅ G_3. If f: V(G_1) → V(G_2) and g: V(G_2) → V(G_3) are isomorphisms, their composition (g ∘ f): V(G_1) → V(G_3) is a bijection that preserves all adjacencies.

Conclusion: Since isomorphism satisfies reflexivity, symmetry, and transitivity, it is a valid Equivalence Relation, partitioning the set of graphs into disjoint isomorphism classes.

Question 29 (ID: 29, Marks: 3 Marks):
Topic: Set Theory
Question: What is the difference between a Proper Subset, an Improper Subset, and a Power Set?

Model Solution / Answer:
Proper Subset, Improper Subset, and Power Set:

1. Subset (A ⊆ B):
A set A is a subset of B if every element of A is also an element of B:
∀x (x ∈ A → x ∈ B).

2. Proper Subset (A ⊂ B):
A is a proper subset of B if A is a subset of B and A is not equal to B (there exists at least one element in B that is not in A):
A ⊆ B and A ≠ B.
Example: If B = {1, 2, 3}, then A = {1, 2} is a proper subset of B.

3. Improper Subset:
A subset A of B that is equal to B itself is called an improper subset of B. Every non-empty set has exactly one improper subset: the set itself.

4. Power Set (P(A)):
The power set of a set A, denoted P(A), is the set of all subsets of A:
P(A) = { S | S ⊆ A }.
If |A| = n, then the cardinality of the power set is |P(A)| = 2^n.

Question: What is the basic idea if Mathematical Induction?

Model Solution / Answer:
Mathematical Induction Principle:
Mathematical induction is a powerful proof technique used to prove that a property P(n) holds for all positive integers n ≥ n0.
Two Crucial Steps:
1. Basis Step (Base Case): Prove that the statement P(n0) is true for the smallest initial integer (usually n = 1 or n = 0).
2. Inductive Step: Assume that P(k) is true for an arbitrary integer k ≥ n0 (Inductive Hypothesis). Under this assumption, prove that P(k + 1) must also be true.
Conclusion: Since the base step and the inductive step are both verified, P(n) is true for all integers n ≥ n0.

Question 51 (ID: 51, Marks: 3 Marks):
Topic: Relations & Partitions
Question: Define symmetric and anti-symmetric.

Model Solution / Answer:
Definitions of Symmetric and Anti-Symmetric Relations:
1. Symmetric Relation:
A binary relation R on a set A is symmetric if for all a, b ∈ A, whenever (a, b) ∈ R, then (b, a) ∈ R.
Example: If A = {1, 2}, R = {(1, 2), (2, 1), (1, 1)} is symmetric.

2. Anti-Symmetric Relation:
A binary relation R on a set A is anti-symmetric if for all a, b ∈ A, whenever (a, b) ∈ R and (b, a) ∈ R, then a = b. (Equivalently, if a ≠ b and (a, b) ∈ R, then (b, a) ∉ R).
Example: The 'less than or equal to' (≤) relation on integers is anti-symmetric because if x ≤ y and y ≤ x, then x = y.

  √(x - 4) ≥ 0 for all x ≥ 4.
  Thus, Range = [0, ∞).

Model Solution / Answer:
Königsberg Bridges Problem:
The Seven Bridges of Königsberg is a historically famous mathematical problem solved by Leonhard Euler in 1736, which laid the foundation of Graph Theory.
Problem Statement: Can a walker cross all seven bridges over the Pregel River in Königsberg exactly once and return to the starting point?
Euler's Solution & Significance:
Euler represented the landmasses as vertices and the bridges as edges (a multigraph). He proved that a continuous walk crossing every edge exactly once (an Eulerian path/circuit) exists if and only if the graph is connected and all vertices (or all except exactly two) have an EVEN degree. Because all four landmasses had odd degrees (3, 3, 3, and 5), such a path is mathematically impossible.

Model Solution / Answer:
Conditional Statement and Its Three Variations:
Given a conditional statement 'If p, then q' (p → q):
1. Conditional Statement (p → q): True in all cases except when hypothesis p is True and conclusion q is False.
2. Converse (q → p): Formed by swapping the hypothesis and conclusion. Note: (p → q) is NOT logically equivalent to its converse.
3. Inverse (~p → ~q): Formed by negating both hypothesis and conclusion. Note: Inverse is logically equivalent to the converse.
4. Contrapositive (~q → ~p): Formed by swapping and negating both hypothesis and conclusion. Key Rule: A conditional statement is ALWAYS logically equivalent to its contrapositive (p → q ≡ ~q → ~p).

Model Solution / Answer:
Definition and Principles of Recursion:
1. Definition:
Recursion is a method of defining an object, function, sequence, or set in terms of smaller or simpler instances of itself.
2. Two Fundamental Components of a Recursive Definition:
   (a) Base Case (Anchor): Defines the value or state of the object for the initial, simplest input without using recursion (e.g., f(0) = 1). This provides the termination condition to prevent infinite regression.
   (b) Recursive Step (Inductive Step): Specifies a rule for calculating the value of the function at a larger argument n in terms of its values at preceding smaller arguments (e.g., f(n) = n · f(n - 1) for n ≥ 1).

   - Recursive Rule: n! = n × (n - 1)! for all integers n ≥ 1.

Function Verification Criteria:

A binary relation f ⊆ A × B is a function from A to B (denoted f: A → B) if and only if it satisfies two strict conditions:

1. Domain Condition (Total Definition):
Every element of the domain set A must be the first coordinate of at least one ordered pair in f:
∀x ∈ A, ∃y ∈ B such that (x, y) ∈ f (i.e., Dom(f) = A).

2. Well-Defined / Single-Valued Condition (Uniqueness):
No element of A may be associated with more than one distinct element of B:
If (x, y1) ∈ f and (x, y2) ∈ f, then y1 = y2.

Visual / Graphical Tests:
- Arrow Diagram: Exactly one arrow must emanate from every element in set A.
- Cartesian Graph: The relation satisfies the Vertical Line Test (every vertical line x = c for c ∈ A intersects the graph at exactly one point).

Question 102 (ID: 102, Marks: 8 Marks):
Topic: Logic & Propositions
Question: Test the following argument for validity:
Premise 1: Logic is difficult or not many students like logic.
Premise 2: If Mathematics is easy, then logic is not difficult.
Conclusion: Therefore, Mathematics is not easy or logic is difficult.

Model Solution / Answer:
Validity Test of Propositional Argument:

1. Symbolic Formulation:
Let:
  d = 'Logic is difficult'
  s = 'Many students like logic' (so ~s = 'Not many students like logic')
  m = 'Mathematics is easy'

Argument Form:
  Premise 1: d ∨ ~s
  Premise 2: m → ~d
  Conclusion: ~m ∨ d

2. Critical Row Analysis (Testing for Invalidity):
An argument is valid if and only if in every row where ALL premises are True (critical row), the conclusion is also True.
If there exists even one row where premises are True and conclusion is False, the argument is INVALID.

Let us test whether the conclusion ~m ∨ d can be False:
  ~m ∨ d = False requires both ~m = False (so m = True) and d = False.
Now substitute m = True and d = False into the premises:
  - Premise 2: m → ~d becomes True → ~(False) = True → True = True.
  - Premise 1: d ∨ ~s becomes False ∨ ~s. If we assign s = False, then ~s = True, making Premise 1 = False ∨ True = True.

3. Counterexample Found:
At truth assignment m = True, d = False, s = False:
  - Premise 1 (d ∨ ~s): True
  - Premise 2 (m → ~d): True
  - Conclusion (~m ∨ d): False

Conclusion: Because there is a critical row where all premises are True but the conclusion is False, the argument is INVALID (Fallacious).

Question 103 (ID: 103, Marks: 9 Marks):
Topic: Relations & Partitions
Question: Let A = {a, b, c, d}. Define the null relation ∅ and the universal relation A × A on A. Test both relations for reflexive, symmetric, and transitive properties.

Model Solution / Answer:
Analysis of Null Relation and Universal Relation on Set A = {a, b, c, d}:

1. Null Relation R1 = ∅ on A:
  a. Reflexive: False (Irreflexive). For R1 to be reflexive, (x, x) ∈ R1 for all x ∈ A. Since A is non-empty, (a, a) ∉ ∅, so ∅ is NOT reflexive.
  b. Symmetric: True. The condition 'if (x, y) ∈ ∅ then (y, x) ∈ ∅' is vacuously true because the antecedent (x, y) ∈ ∅ is always False.
  c. Transitive: True. The condition 'if (x, y) ∈ ∅ and (y, z) ∈ ∅ then (x, z) ∈ ∅' is vacuously true because the hypothesis is always False.
  Note: ∅ is also antisymmetric (vacuously true), but is not an equivalence relation because it lacks reflexivity.

2. Universal Relation R2 = A × A on A:
  a. Reflexive: True. For every x ∈ A, (x, x) ∈ A × A by definition of the Cartesian product.
  b. Symmetric: True. For any (x, y) ∈ A × A, (y, x) ∈ A × A since x, y ∈ A.
  c. Transitive: True. For any (x, y) ∈ A × A and (y, z) ∈ A × A, (x, z) ∈ A × A.
  Note: Universal relation R2 satisfies all three properties and is therefore an Equivalence Relation on A (with a single equivalence class containing all elements of A).

Question 104 (ID: 104, Marks: 4 Marks):
Topic: Functions & Mappings
Question: Let f and g be functions from the set of integers to the set of integers defined by f(x) = 2x + 3 and g(x) = 3x + 2. What is the composition of f and g (f ∘ g)? What is the composition of g and f (g ∘ f)?

Model Solution / Answer:
Composition of Linear Functions on Integers:

1. Given:
  f: Z → Z, f(x) = 2x + 3
  g: Z → Z, g(x) = 3x + 2

2. Composition (f ∘ g)(x):
  (f ∘ g)(x) = f(g(x))
             = f(3x + 2)
             = 2(3x + 2) + 3
             = 6x + 4 + 3
             = 6x + 7.

3. Composition (g ∘ f)(x):
  (g ∘ f)(x) = g(f(x))
             = g(2x + 3)
             = 3(2x + 3) + 2
             = 6x + 9 + 2
             = 6x + 11.

Conclusion: (f ∘ g)(x) = 6x + 7 and (g ∘ f)(x) = 6x + 11. Since 6x + 7 ≠ 6x + 11 for any integer x, f ∘ g ≠ g ∘ f.

Question 105 (ID: 105, Marks: 9 Marks):
Topic: Sequences & Recurrence
Question: If the 5th element of an arithmetic sequence is -16 and the 20th term is -46, find the 10th term using the proper formula of arithmetic sequence.

Model Solution / Answer:
Step-by-Step Solution Using Arithmetic Progression Formula:

1. Arithmetic Sequence General Term Formula:
  a_n = a_1 + (n - 1)d,
  where a_1 is the first term and d is the common difference.

2. Setting Up Simultaneous Equations:
  From the 5th term (n = 5):
    a_5 = a_1 + 4d = -16      --- (Equation 1)
  From the 20th term (n = 20):
    a_20 = a_1 + 19d = -46    --- (Equation 2)

3. Solving for Common Difference (d):
  Subtract Equation 1 from Equation 2:
    (a_1 + 19d) - (a_1 + 4d) = -46 - (-16)
    15d = -30
    d = -30 / 15 = -2.

4. Solving for First Term (a_1):
  Substitute d = -2 into Equation 1:
    a_1 + 4(-2) = -16
    a_1 - 8 = -16
    a_1 = -16 + 8 = -8.

5. Calculating the 10th Term (a_10):
  a_10 = a_1 + (10 - 1)d
       = a_1 + 9d
       = -8 + 9(-2)
       = -8 - 18
       = -26.

Final Answer: The 10th term of the arithmetic sequence is -26.

Question 106 (ID: 106, Marks: 5 Marks):
Topic: Sequences & Recurrence
Question: Show that the sequence c_n = 2^n - 1, for n ≥ 0 (terms 0, 1, 3, 7, ...), satisfies the recurrence relation c_k = 2c_{k-1} + 1 for all integers k ≥ 1.

Model Solution / Answer:
Verification of Recurrence Relation Solution:

1. Given Explicit Formula:
  c_n = 2^n - 1, for integers n ≥ 0.

2. Recurrence Relation to Verify:
  c_k = 2c_{k-1} + 1, for all integers k ≥ 1.

3. Algebraic Proof (Substituting Formula into Recurrence):
  From the explicit formula:
    c_k = 2^k - 1
    c_{k-1} = 2^{k-1} - 1
  Evaluate the Right Hand Side (RHS):
    RHS = 2 · c_{k-1} + 1
        = 2 · (2^{k-1} - 1) + 1
        = (2 · 2^{k-1}) - 2 + 1
        = 2^{(k-1)+1} - 1
        = 2^k - 1
        = c_k = LHS.

4. Base Condition Check:
  For k = 1: c_0 = 2^0 - 1 = 1 - 1 = 0.
  From recurrence: c_1 = 2(c_0) + 1 = 2(0) + 1 = 1.
  From explicit formula: c_1 = 2^1 - 1 = 1. (Consistent).

Conclusion: Since LHS = RHS for all integers k ≥ 1, the sequence c_n = 2^n - 1 satisfies the recurrence relation c_k = 2c_{k-1} + 1.
