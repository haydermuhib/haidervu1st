Question: Who is a Computing Professional, and what ethical responsibilities do they have?

Model Solution / Answer:
Who is a Computing Professional:
A Computing Professional is a skilled practitioner whose primary vocation involves computer hardware, software engineering, systems design, network administration, database management, or information security.
Key Characteristics and Responsibilities:
1. Specialized Knowledge: Possesses formal expertise in algorithmic thinking, programming languages, system architecture, and data structures.
2. Adherence to Professional Ethics: Follows established codes of conduct (such as the ACM/IEEE-CS Code of Ethics) emphasizing public welfare, privacy, data confidentiality, and software safety.
3. Quality and Reliability: Commits to building robust, defect-free, secure software systems and avoiding malicious or negligent coding practices.
4. Continuous Learning: Maintains currency with evolving technology, security vulnerabilities, and industry standards.

Question 8 (ID: 8, Marks: 5 Marks):
Topic: JavaScript & Programming
Question: Given the following JavaScript code segment:
<script>
Number = new Array(5);
var abc = 4;
for (var i = 1; i <= 5; i = i + 1) {
    Number[i] = abc * i;
}
Number.reverse();
for (j = 0; j < 5; j = j + 1) {
    document.write(" " + Number[j] + "<BR>");
}
</script>
A) What is the exact output of the above code?
B) Explain the function of Number.reverse() and the loop execution.

Model Solution / Answer:
Solution:
A) Output of the code:
20
16
12
8
4

B) Technical Explanation of Code Lines:
1. 'Number = new Array(5); var abc=4;': Instantiates an Array object with initial size 5 and initializes variable abc to 4.
2. 'for(var i=1; i<=5 ; i=i+1) { Number[i]= abc*i; }': Loops 5 times. It assigns values to indices 1 through 5:
   Number[1]=4, Number[2]=8, Number[3]=12, Number[4]=16, Number[5]=20. (Note: in JavaScript, array index 0 remains undefined, and length expands to 6).
3. 'Number.reverse();': Inverts the order of elements in place. Index 0 becomes 20, index 1 becomes 16, index 2 becomes 12, index 3 becomes 8, index 4 becomes 4, and index 5 becomes undefined.
4. 'for(j=0;j<5;j=j+1) { document.write(" "+Number[j]+"<BR>"); }': Iterates from index j = 0 to 4, printing each value on a new line.

Question 33 (ID: 33, Marks: 5 Marks):
Topic: Algorithms & Problem Solving
Question: Elaborate greedy algorithm definition with solid example in favour and one counter example?

Model Solution / Answer:
Greedy Algorithm:
1. Definition: An algorithmic paradigm that builds up a solution piece by piece, always choosing the immediate next piece that offers the most obvious and immediate benefit (locally optimal choice) in hopes of finding a global optimum.
2. Example in Favor (Optimal): Kruskal's or Prim's algorithm for finding the Minimum Spanning Tree (MST) in a weighted graph, or Huffman Coding.
3. Counter-Example (Fails Global Optimum): 0/1 Knapsack Problem or Finding the shortest path in a graph where a locally expensive bridge leads to a vastly shorter total route.

Model Solution / Answer:
A part of disk storage can be made to behave like RAM. This is known as Virtual Memory. When a file or program is too big for the computer to work with in its memory, part of the data is stored on disk. This virtual storage is divided into segments called pages; each page is correlated with a location in physical memory, or RAM. When a page, which is not currently in the main memory, is referenced, it is swapped into memory and is sent back to disk when other pages must be called and loaded into main memory in place of the old one. The program runs as if all the data is in memory.

Question 152 (ID: 152, Marks: Short Question):
Topic: General Computer Science
Question: What is plotter?

Model Solution / Answer:
The device used to draw charts, diagrams, and other line-based graphics. Plotters use either pens or electrostatic charges and toner (Powdered pigment that is used in office copiers and in laser, LED, and LCD printers. Pen plotters draw on paper or transparencies with one or more colored pens. Electrostatic plotters "draw" a pattern on electro statically charged dots on the paper and then apply toner and fuse it in place. Plotters use three basic types of paper handling: flatbed, drum, and pinch roller. Flatbed plotters hold the paper still and move the pen along both x and y axes. Drum plotters roll the paper over a cylinder. The pen moves along one axis while the drum, with the paper attached, moves along the other. Pinch-roller plotters are a hybrid of the two, in which the pen moves only along one axis while the paper is moved back and forth by small rollers. Question: Write a technical note explaining the Image Preloading process in JavaScript and Animated GIFs.

Model Solution / Answer:
Technical Note on Image Preloading and Animated GIFs:

1. Image Preloading Process:
   - Purpose: In interactive web pages (such as rollover buttons and carousels), requesting an image only when the user hovers causes noticeable delay while the image downloads over the network.
   - Mechanism: JavaScript preloads images into the browser cache ahead of time using the `Image` object constructor:
     var preloadedImg = new Image();
     preloadedImg.src = 'button_hover.png';
   - Benefit: When the mouseover event triggers, the image is fetched instantly from local memory cache without latency.

2. Animated GIFs:
   - An image format that combines multiple raster bitmap frames into a single file played sequentially in an endless loop.
   - It uses 8-bit color palette (maximum 256 colors) and LZW lossless compression.

Question 230 (ID: 230, Marks: 5 Marks):
Topic: General Computer Science
Question: Differentiate clearly between Shareware and Trialware software with examples.

Model Solution / Answer:
Differences Between Shareware and Trialware:

1. Shareware:
   - Concept: Commercial software distributed freely on a 'try before you buy' basis.
   - Usage: Users are encouraged to share and test the program for a trial period. Full features are often available, but users are expected to pay a registration license fee to continue using it legally.
   - Example: WinRAR, early IDM.

2. Trialware (Demoware):
   - Concept: A time-limited or feature-restricted version of commercial software designed specifically to demonstrate functionality.
   - Restrictions: Strictly disables core capabilities (e.g., cannot save, cannot export, or expires completely after 30 days) unless an activation license key is purchased.
   - Example: Adobe Photoshop 30-Day Trial, commercial antivirus suites.
